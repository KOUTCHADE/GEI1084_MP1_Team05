# Résultats de validation - CMP

Ce dossier regroupe les preuves de simulation de l'instruction CMP du processeur ARM monocycle.

Les tests C1, C2, C3, C4, C6 et C7 ont été validés dans Vivado. Le bilan actuel est de 26 tests exécutés, avec aucune erreur détectée.

Le test C5, consacré au débordement signé, reste à compléter.

Les preuves de validation comprennent les chronogrammes Vivado, les résultats du testbench et les observations permettant de comparer les résultats obtenus aux résultats attendus.
